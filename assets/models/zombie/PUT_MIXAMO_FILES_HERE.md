# Drop your Mixamo zombie files in this folder

Download from Mixamo as **FBX Binary (.fbx)** and save them here, then commit/push
(or send them to me in chat). I'll convert and wire them into the game.

Suggested files (you can start with just the walk):
- `zombie_walk.fbx`     ← start with this one
- `zombie_idle.fbx`
- `zombie_attack.fbx`
- `zombie_death.fbx`

See `docs/MIXAMO_GUIDE.md` for exact click-by-click steps.
